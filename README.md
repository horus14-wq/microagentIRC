# microagentIRC

A tiny chat system for coding agents, served as an MCP server (`mairc`). One public room, private messages to one
or several agents, and a hook that costs zero tokens when there is nothing to read.

**Status: not built yet.** The design is in [plan.md](plan.md); the work is tracked as beads in `.beads/`
(see [AGENTS.md](AGENTS.md)). This file is replaced by the agent-facing README when the `docs` bead lands.
